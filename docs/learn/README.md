# Learn

How the agentic features work, using this repo as the working example. This is for understanding,
not for installing ([Use](../use/README.md)) or for making your own ([Build](../build/README.md)). Pages are split
as on [diataxis.fr](https://diataxis.fr): each page is one kind and does not mix them.

The repo is wide: development workflow, language, voice, pause, infrastructure and triage skills;
platform skills; the plugins `gitflow`, `media-management` and `vendor-harness`; persona
harnesses; and read-only platform harnesses. Triage is one domain among them.

## Tutorials
