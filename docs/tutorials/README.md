# Tutorials

Lessons that teach by doing. Each one takes you from nothing to something that works, on one path, and shows what you should see at every step. If you want to solve a problem you already understand, use the how-to guides instead.

| Tutorial | What you will build |
|---|---|
| [Your first triage run](first-triage-run.md) | A read-only ynh harness that answers "who is waiting on a reply from me?" in Messages, using a fake `chat.db` so it needs no accounts and no credentials |

The tutorials follow the [ynh tutorial](https://github.com/eyelock/ynh/tree/develop/docs/tutorial) conventions: commands you can paste, then a block showing what you should see.
