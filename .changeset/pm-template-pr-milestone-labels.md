The programme-manager charter template may, on a pull request in the repositories it reads, set or clear its milestone, add or remove its labels, and add it to or move it on the roadmap project. It does this only where the tracker is also the code host (GitHub Issues on GitHub); elsewhere it proposes the change to the humans instead. Every other pull request action (code, title, body, draft state, comments, reviews, approval, merge, push, opening one) stays under "May not", and a seat added from the template carries the same words.
