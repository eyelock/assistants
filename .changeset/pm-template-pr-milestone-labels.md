The programme-manager charter template may, on a pull request in the repositories it reads, set or clear its milestone, add or remove its labels, and add it to or move it on the roadmap Projects. Every other pull request action (code, title, body, draft state, comments, reviews, approval, merge, push, opening one) stays under "May not", and a seat added from the template carries the same words.
