The programme-manager charter template places each open bug by its priority without asking the humans: a P0 or P1 bug goes to the tool's next patch milestone (created as a patch release if missing), and a lower-priority bug to the next open minor milestone, or the next patch milestone when there is none. Creating a patch milestone for a bug is no longer one of the things it reviews with the humans first; it tells them only when a placement would change a release's theme.
