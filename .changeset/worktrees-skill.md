A new `worktrees` skill, so a seat never invents a worktree path. `scripts/worktree.sh add --seat S --repo R --branch B [--bead ID]` makes the worktree at the path the Wheelhouse's policy gives, prints the absolute path and nothing else, and appends the line `Worktree: <path>` to the bead's notes as the seat, which `list` and `remove` find again with a single `bd list --notes-contains` call, however many beads the graph holds; a new branch must start with `<seat>/`. `list` shows every worktree of every repository the Wheelhouse reaches with its seat, repo, branch, bead and path, and flags those whose bead is closed or whose branch is merged (`--stale` keeps only those). `remove <path> --seat S` removes the seat's own worktree, or any seat's once its bead is closed when the dispatcher asks, and refuses a path outside the layout, uncommitted work and anything that would need `--force`; it never prunes, moves, locks or repairs. The policy is `worktrees.json` in the Wheelhouse root beside `tracker.json`, `{"layout": "{repo}/.worktrees/{seat}/{branch}"}`; with no file the layout is `{scratchpad}/{repo}/{branch}`.
