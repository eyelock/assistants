Add rekordbox-mcp integration and a `/setup` onboarding skill; relocate `config.json` out of the repo. The `rekordbox-database` MCP server (from davehenke/rekordbox-mcp, path via `MEDIA_MGMT_REKORDBOX_MCP_PATH`) is declared in `.mcp.json` with its tools auto-approved via hooks. `config.json` is no longer shipped in the repo — it's a per-user file at `$MEDIA_MGMT_CONFIG_PATH` (default `~/.config/media-management/config.json`); existing installs relying on the old project-root `config.json` should run `/media-management:setup` or set the `MEDIA_MGMT_*` env vars directly. `/setup` checks all required paths, walks the user through filling in anything missing, and writes `config.json`; a `SessionStart` hook nudges toward it when config is incomplete, and a `PreToolUse` hook blocks the config-dependent skills (`process-album`, `select-release`, `cleanup`, `manage-metadata`, `import-to-apple-music`, `archive-media`) until it's fixed. Also fixes a stale hardcoded script path in `select-release`, and adds `evals/` (output-quality test cases, trigger-eval queries, and a fixture generator) for every skill per the agentskills.io skill-authoring guides — tightening three skill descriptions based on real trigger-eval results (97/101 → 101/101 pass rate, zero false positives).
