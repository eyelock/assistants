Seats name things fully. create-wheelhouse writes a rule into the constitution, and add-seat repeats it in every seat's charter: in everything a seat writes for people, a web resource (a pull request, issue, CI run, review, commit or page) is named by its short form as a Markdown link, never a bare `#12` or a bare URL, and a local path is given in full, almost never relative. Code and config keep portable relative paths. Each Wheelhouse fills in the examples from its own reach.
