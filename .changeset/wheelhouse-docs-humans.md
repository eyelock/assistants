The docs catch up with the humans and the inbox. The plugin README's layers and skills tables name the humans, the default human and the inbox, and what `work-graph`, `wake` and `doctor` do about them; the Wheelhouse overview says who the humans are and how a seat asks one for something, with the `repo:` label from `--repo` or the bead it blocks. The `wake` skill's fallback, when there is no wake script, has the desk run `inbox.sh show` too. `inbox.sh`'s usage for `show` lists the `email` and `priority` fields it prints.
