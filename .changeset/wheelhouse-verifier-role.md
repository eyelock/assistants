The `add-seat` starter team gains an optional verifier: a standing role, on the deep tier and seated by the desk, that checks after a set of changes has landed (and before a release) that the whole behaves as intended, apart from per-pull-request review. It builds each tool in its own scratch worktree, runs the record's claims live, and files a bead for each one that is wrong. The add-seat skill and the plugin README list it, and the seat-model test covers its tier.
