A `refresh` skill, the desk's, for applying merged changes after a pull. Its `scripts/refresh.sh` reads `git diff --name-only` (default `ORIG_HEAD..HEAD`) and maps each path to what it needs: `ynh install harnesses/<seat>` for a seat's folder, `ynh install .` and every seat for the root `AGENTS.md`, the root harness `plugin.json` or the roster (and the seats that pick a desk skill), a printed `ynh trust accept local/<seat>` (never run) for every roster seat that `ynh trust ls --format json` reports `changed` or `unreviewed` after the installs and updates, and for any change in the diff to a seat's sensors, hooks, MCP servers, workspace, profiles (hooks, MCP servers, sensors and includes), launch focus or `delegates_to` entries, restarts for `scripts/`, and nothing for docs. It runs the safe installs, then the doctor, and prints which seats to restart. With no diff, or `--upstream`, it also offers `ynh update local/<seat>` for a stale cached wheelhouse include, and `--update` runs it and re-copies the plugin scripts the Wheelhouse carries. The diff cannot see a delegate focus's prompt or what an include brings in; those show only through `ynh trust ls`, after the installs. It notes any seat ynh lists as `unavailable` (an include that isn't cached), with ynh's problems and that `ynh update` fixes it where `ynh trust accept` can't. It reports every roster seat that isn't installed or born, with the install command and whose birth it is. `--dry-run` only prints.
