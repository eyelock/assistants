Seats are born and wake as themselves: a `birth` skill for a seat's first session (its own identity, pinned in its own namespace) and a `wake` skill and script that start every session with purpose. work-graph gains dispatching and assigned-first pickup; add-seat creates the worker fleet as one shared harness. handoff keeps its notes as episodic memory in the seat's namespace, since ynm drops working memory when a session ends.
