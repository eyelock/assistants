The plugin gains `lib/wheelhouse-lib.sh`, one library for the helpers every script used to carry its own copy of, and every script sources it from beside itself or from the plugin's `lib/` folder. It holds `limited` (now killing the process group everywhere, and saying so when perl is missing instead of running unbounded in silence), `die`, `need`, `bd_data` and `bd_first` for the `{"data": ...}` envelope, the roster path, `wl_backend`, `wl_is_seat` and `wl_is_trial_seat`, the command-name rule, `wl_has_git_remote` and `wl_dolt_remote`, `wl_born_by` and `wl_identity_pinned`, and the model tiers. Every outside call (`bd`, `gh`, `ynh`, `ynm`) in a script now goes through `limited`, with a limit set by `WL_BD_SECS`, `WL_GH_SECS`, `WL_YNH_SECS`, `WL_YNM_SECS` or `WL_SYNC_SECS`. A Wheelhouse that carries copies of the scripts must carry `scripts/wheelhouse-lib.sh` beside them: `create-wheelhouse` copies it, and `refresh --update` brings it in. `memory.sh` now takes only a command name (lower-case letters, digits and hyphens) for `--seat`, `--human` and `--actor`, as `inbox.sh` and `ask.sh` already did.
