# Waiting On Them

The user asked someone for something, and they have not done it. Follow the rules and answer
shape in `triage-report`.

## What counts

An item waits on someone else when **all** of these hold:
- the user asked a person or a group for something: a review, an answer, a decision, a
  response to an invite;
- it calls for an action from them, not from the user;
- they have not done it since: no reply, no review, no response.

It does **not** count when:
- the user's message needed no answer: a thank-you, an announcement, a status update;
- the latest step is the user's to take: changes were requested, or a question came back.
  That is waiting on the user (see `waiting-on-me`);
- it is a draft or otherwise not ready for anyone to act on.

## How to look

1. Learn who the user is, as `triage-report` says.
2. Find what the user sent, opened or organized that asks something of others. The platform
   harness's instructions name the tools and queries.
3. For each, check whether the other side acted since. **Who** is the person being waited on;
   when it is a group, name the group.

**Since** is when the user asked, or last nudged.
